# Wireframes

Wireframes de baja fidelidad para validar jerarquía, navegación y estados antes
del diseño visual.

## Documentos

| Documento | Contenido |
|---|---|
| [`publico.md`](publico.md) | Home, galería, detalle, video, colección, búsqueda, about, contacto. |
| [`admin.md`](admin.md) | Login, dashboard, biblioteca, subida, metadatos, publicación, ajustes. |
| [`estados.md`](estados.md) | Vacío, carga, error, 404, 410, 503, offline. |

## Convenciones

- `[ ]` botón o enlace.
- `( )` control de formulario.
- `▣` imagen o medio.
- `···` texto.
- `↕` scroll.
- Las anotaciones van debajo de cada bloque.
- El orden de lectura debe coincidir con el orden visual.
- Ningún wireframe depende del color para comunicar.
