# Glosario

| Término | Definición |
|---|---|
| **Access** | Cloudflare Access: capa de autenticación delante del admin; solo identidades autorizadas pasan. |
| **AVIF / WebP** | Formatos de imagen modernos con mejor compresión que JPEG. |
| **BullMQ** | Cola de trabajos sobre Redis para procesar medios y builds de forma asíncrona. |
| **Caddy** | Servidor web y reverse proxy usado para servir el sitio y el admin. |
| **CDN** | Red de nodos que sirve contenido desde la ubicación más cercana al visitante. |
| **CLS** | Cumulative Layout Shift: estabilidad visual; objetivo ≤ 0,05. |
| **Core Web Vitals** | LCP, INP y CLS; métricas de experiencia de carga e interacción. |
| **CSP** | Content Security Policy: cabecera que limita qué recursos puede cargar la página. |
| **Drizzle** | ORM/query builder TypeScript para PostgreSQL. |
| **FFmpeg / ffprobe** | Herramientas de transcodificación y análisis de video. |
| **HLS** | HTTP Live Streaming: video adaptativo por segmentos. |
| **hreflang** | Etiqueta que indica la versión de idioma/región de una página. |
| **INP** | Interaction to Next Paint: respuesta a interacciones; objetivo ≤ 200 ms. |
| **LCP** | Largest Contentful Paint: carga del elemento principal; objetivo ≤ 2,0 s en p75 móvil. |
| **LUKS** | Cifrado de disco completo en Linux. |
| **Passkey / WebAuthn** | Autenticación sin contraseña con una clave criptográfica del dispositivo. |
| **PostgreSQL** | Base de datos relacional principal. |
| **Presigned URL** | URL temporal firmada que autoriza una operación concreta sobre un objeto. |
| **R2** | Almacenamiento de objetos de Cloudflare compatible con S3, sin cargo de egreso. |
| **RPO / RTO** | Punto y tiempo máximos de recuperación aceptables tras un desastre. |
| **restic** | Herramienta de backup cifrado y deduplicado. |
| **sharp / libvips** | Librería de procesamiento de imágenes de alto rendimiento. |
| **SSG** | Generación estática del sitio en build. |
| **SSRF** | Server-Side Request Forgery: forzar al servidor a pedir recursos internos o ajenos. |
| **STRIDE** | Metodología de modelado de amenazas: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege. |
| **Tunnel** | Cloudflare Tunnel: conexión saliente cifrada desde el servidor; no requiere abrir puertos. |
| **Turnstile** | CAPTCHA invisible de Cloudflare para formularios. |
| **WAL** | Write-Ahead Log de PostgreSQL; permite recuperación tras un corte. |
| **WCAG 2.2 AA** | Nivel de accesibilidad objetivo del sitio y del admin. |
